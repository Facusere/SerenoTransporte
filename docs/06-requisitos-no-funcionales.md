# 06 · Requisitos no funcionales

| ID | Requisito | Detalle |
|---|---|---|
| RNF01 | Simplicidad | Cargar un parte en pocos toques; papá prefiere **escribir**; pantallas con letra grande |
| RNF02 | Multiplataforma | iPhone (papá y choferes) y Chrome en computadora (mamá); mismos datos en tiempo real |
| RNF03 | Conectividad | Hay señal en toda la zona: **no se exige sincronización offline distribuida de varios días**, pero sí **persistencia local del borrador en el navegador** (ver RNF17 y RF41) ante microcortes de señal y un respaldo exportable (ver RF35) |
| RNF04 | Seguridad | Login, roles, conexión cifrada; sueldos, cheques y finanzas personales protegidos |
| RNF05 | Privacidad | Repo y datos privados; el repo no contiene datos reales de empleados |
| RNF06 | Backups | Copias automáticas y restauración probada |
| RNF07 | Costo | Bajo o nulo costo mensual |
| RNF08 | Mantenibilidad | Código y documentación claros para retomar |
| RNF09 | Disponibilidad | Que funcione de madrugada y a la noche; datos accesibles siempre |
| RNF10 | Exportabilidad | Datos exportables a **Excel y PDF**; nunca "atrapados" |
| RNF11 | Auditoría | Historial de cambios en sueldos, cheques y partes |
| RNF12 | Fotos | Almacenar fotos de tickets y comprobantes con tamaño razonable |
| RNF13 | Parámetros configurables | Tarifas, margen de error, tope de adelantos y valores de sueldo no van fijos en el código |
| RNF14 | Integraciones externas | Holistor y ARCA quedan fuera del sistema; se vinculan solo por archivos |
| RNF15 | Uso en cabina | Pantallas pensadas para cargar con el camión detenido; botones grandes; contraste legible al sol |
| RNF16 | Compatibilidad de celulares | Funciona en iPhone y Android, incluso modelos de hace varios años (a verificar con los choferes) |
| RNF17 | Autoguardado | Ningún dato cargado se pierde por cerrar la app o perder señal |
| RNF18 | Datos móviles | Fotos comprimidas; la app no gasta datos en segundo plano |
| RNF19 | Auditoría laboral | Los registros de horas guardan sello de tiempo y cambios; consulta con el contador sobre su archivo |
| RNF20 | Soporte | Un responsable definido para altas, PIN y consultas de choferes |
