# 04 · Glosario

| Término | Definición (a validar) |
|---|---|
| Viaje | Salida de un camión que carga leche y la descarga en una fábrica |
| Recorrido | Ruta con tambos/campos en orden que recorre un camión |
| Tambo / campo | Establecimiento productor donde se carga la leche |
| Fábrica | Destino de descarga (cliente) |
| Litros cargados | Litros levantados en los tambos |
| Litros descargados | Litros entregados en la fábrica |
| Merma / diferencia | Litros cargados − descargados |
| Precio por litro | Valor pagado por litro; puede variar por recorrido/fábrica/fecha |
| Adelanto | Dinero entregado a un empleado antes del sueldo, descontable |
| Franco | Día libre del empleado |
| Chofer | Empleado que conduce un camión |
| Repuesto | Pieza o servicio para mantenimiento de un camión |
| Liquidación | Cálculo mensual del sueldo |
| Parte diario | Registro de lo que hizo un chofer en el día (recorridos, horas, km, litros, controles) |
| Corta distancia | Chofer pagado por horas: básico, antigüedad, extras, viáticos, comida |
| Larga distancia | Chofer pagado por km/viajes: básico, antigüedad, km, viáticos por km |
| Caudalímetro | Medidor de litros del camión o de la fábrica; emite ticket |
| Acidez (prueba) | Control previo a la carga; si es ácida, no se carga |
| Margen de error | Diferencia permitida entre litros cargados y descargados: **0,2 %**, evaluada **sobre el total del mes** |
| Liquidación de fábrica | Resumen mensual que envía la empresa con viajes, litros, km y montos |
| Orden de pago | Documento de la fábrica que acompaña el cobro |
| e-cheq | Cheque electrónico |
| Retención | Importe que la fábrica retiene al pagar (ganancias, IIBB, seg. social) |
| Franco no gozado | Franco no tomado por el chofer, que se paga aparte |
| Holistor | Software del estudio contable para el recibo de sueldo legal |
| ARCA | Organismo donde se emiten y consultan comprobantes (ex AFIP) |
| Ámbito | Marca para separar gastos de la empresa de los personales |
| Plantilla de recorrido | Nombre anterior de la **hoja de ruta global** (ver abajo) |
| Remito | Comprobante por tambo con nº de tambo, fecha, hora y firma del chofer |
| Valor leche | Precio por litro usado para descontar la diferencia que supera el margen |
| Escala salarial | Valores mensuales del convenio (básico, adicionales, viáticos) |
| Valor del día | Importe de domingo trabajado o franco no gozado; **lo fija el sindicato** en la escala mensual |
| Mutual | Entidad que otorga créditos a choferes con garantía de papá |
| Molfino / La Paulina | La Paulina es la marca de los productos de la empresa Molfino |
| Hoja de ruta global | Planilla única que se envía a la planta por mensaje con los recorridos del día |
| FEDCAM | Cámara de transporte que publica la escala salarial mensual |
| Semáforo de vencimientos | Verde vigente, amarillo a 7 días o menos, rojo vencido (así lo usan las empresas) |
| Remuneración / No remunerativo | Parte del sueldo sobre la que se calculan aportes / conceptos como km de ciertos ítems, comida y viático |
| Recibo teórico | Recibo que calcula el sistema con la escala; el recibo legal se emite en Holistor |
| Pago real | Lo que efectivamente se paga: neto del recibo más o menos ajustes |
